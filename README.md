Brief Description:

This project covers creating a Task Management App. Users should be able to add tasks with deadlines, assign categories, and update the status when needed. Task data should also be saved to local storage so it persists after a refresh.

Reflection:

Throughout this project, I encountered problems relating to when to update tasks, use display filters, and save changes. Keeping track of all the functions and when to add certain logic was difficult. Creating dropdown lists was also new to me, so I learned additional information for that, for example, to use the .disabled attribute to hide certain content from being used. 

I used notes to ensure the code was saving to local storage correctly. Throughout the process, I tested the code multiple times throughout to make sure I didn't make too many changes before seeing if there were any errors. I also added more comments as a way to organize the code structure while also serving as a reminder of what the code does and why it needs to be there.

If I had more time, I would add more accessibility elements, especially in the HTML and CSS files. I would also make it more visually appealing through additional CSS styling. More features could've been used, such as editing or creating multiple lists instead of just list items.
